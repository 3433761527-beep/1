# 声屿 MUSIC V3.0（Android）

## V3.0 功能
- 免费完整曲目在线搜索：接入 Audius 官方只读 API。
- 完整歌曲在线播放：通过 Audius 官方 tracks stream endpoint 播放公开且可流式播放的曲目，不限于 30 秒试听片段。
- 热门曲目：加载 Audius 本周热门曲目。
- 搜索排序：综合相关、最受欢迎、最新发布。
- 在线收藏：收藏列表保存在本机。
- 播放控制：播放、暂停、上一首、下一首、进度拖动、随机播放、单曲循环。
- 本地音乐：保留手机音频多选导入、播放、收藏和本地存储。
- 播放来源：提供 Audius 创作者页面链接。

## 曲库、版权和音质说明
- Audius 是创作者发布音乐的开放网络。应用只展示 API 返回的公开、可播放且未标记为流媒体门控的曲目。
- 这不等于全球所有商业歌曲的完整授权曲库；主流唱片公司作品是否可播放取决于权利人和平台授权状态。
- 播放音质取决于创作者上传的原始音源及 Audius 提供的流媒体转码，应用不伪称所有曲目均为 320 kbps 或无损。
- Audius 官方文档说明大多数只读接口可无凭据使用；API key 可提高请求速率。免费 API 方案标注每秒 10 次、每月 500,000 次请求。详见 https://docs.audius.co/sdk/ 和 https://docs.audius.co/api/
- 本应用不会抓取、解密、破解或绕过 Spotify、网易云音乐、QQ 音乐等商业服务的付费/版权保护音源。

## 网络要求
在线搜索和在线播放需要互联网连接。若 Audius API 或流媒体节点在用户所在网络/地区不可达，在线功能可能暂时不可用；本地音乐仍可播放。

## 云端 APK
GitHub Actions 会在 main 分支收到新提交后自动构建 APK。构建成功后，在仓库 Actions 最新运行记录的 Artifacts 中下载 `shengyu-music-debug-apk`，解压得到 `app-debug.apk`。

Debug APK 适用于个人测试和侧载安装，不是 Google Play 发布签名。
